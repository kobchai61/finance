แบบจำลองสมการหลายชั้น

บทที่ 9 · Simultaneous Equation Models · บรรยาย

แนวที่จะถาม

Simultaneous Equation Models มีหลายวิธี วิธีที่เราใช้คือ Two-Stage Least Squares (EViews ใช้ LS – Least Squares สองรอบ) มีหลักการอย่างไร

1.1 แบบจำลองสมการหลายชั้นคืออะไร

ในหลายสถานการณ์ ตัวแปรตามกับตัวแปรอิสระมีความสัมพันธ์ สองทิศทาง คือกำหนดซึ่งกันและกัน จึงพิจารณาสมการใดสมการหนึ่งเพียงสมการเดียวไม่ได้ ต้องพิจารณาทั้งระบบพร้อมกัน

Y1i = β10 + β12Y2i + γ11X1i + u1i
Y2i = β20 + β21Y1i + γ21X2i + u2iY₁, Y₂ เป็นตัวแปรที่สัมพันธ์ซึ่งกันและกัน

ตัวอย่างในสไลด์ (อุปสงค์–อุปทาน) ราคาและปริมาณกำหนดซึ่งกันและกัน วิเคราะห์จากสมการอุปสงค์หรืออุปทานเพียงสมการเดียวไม่ได้

Qtd = α0 + α1Pt + u1t  ·  Qts = β0 + β1Pt + u2t  ·  Qtd = Qts

1.2 ทำไมใช้ OLS ตรงๆ ไม่ได้

ในสมการแรก Y₂ อยู่ด้านขวามือ แต่ Y₂ ขึ้นกับ Y₁ ซึ่งขึ้นกับ u₁ ไล่ตามลูกโซ่ได้ว่า

u1↑  →  Y1↑  →  Y2↑   ⇒   Cov(Y2, u1) ≠ 0

ตัวแปรอธิบายสัมพันธ์กับค่าคลาดเคลื่อน ผิดข้อสมมติของ OLS ทำให้ค่าประมาณ เอนเอียง (biased) และไม่คงเส้นคงวา (inconsistent) เรียกว่า simultaneity bias จึงต้องใช้วิธีเฉพาะของระบบสมการ

1.3 ตรวจปัญหาการระบุก่อน (Identification)

ก่อนประมาณค่าต้องดูว่าสมการ "ระบุได้" หรือไม่ ด้วยเงื่อนไขอันดับ (order condition)

K − k ≥ m − 1M = จำนวนสมการทั้งหมด · m = จำนวนตัวแปรภายในในสมการที่พิจารณา · K = จำนวนตัวแปรทั้งหมดในแบบจำลอง · k = จำนวนตัวแปรทั้งหมดในสมการที่พิจารณา
เงื่อนไขค่าลำดับขั้นของเมทริกซ์ผล
K − k > m − 1rank = M − 1ระบุได้มากเกินไป (over-identified)
K − k = m − 1rank = M − 1ระบุได้อย่างถูกต้อง (exactly identified)
K − k ≥ m − 1rank < M − 1ระบุไม่ได้
K − k < m − 1rank < M − 1ระบุไม่ได้ (under-identified)

เงื่อนไขค่าลำดับชั้น (rank condition): สร้างตารางสัมประสิทธิ์ แถว = สมการ, สดมภ์ = ตัวแปร → ตัดแถวของสมการที่พิจารณา → ตัดสดมภ์ของตัวแปรที่อยู่ในสมการนั้น → เขียนสัมประสิทธิ์ที่เหลือเป็นเมทริกซ์แล้วหา rank

1.4 วิธีประมาณค่า: ILS กับ 2SLS

กำลังสองน้อยที่สุดทางอ้อม (ILS)

แปลงสมการโครงสร้างเป็นสมการลดรูป (reduced form) → ประมาณสมการลดรูปด้วย OLS → ย้อนคำนวณกลับเป็นพารามิเตอร์โครงสร้าง

ปัญหา: บางครั้งย้อนหาพารามิเตอร์โครงสร้างจากค่าลดรูปไม่ได้ (เช่น over-identified ได้คำตอบหลายชุด) ต้องปรับแบบจำลองใหม่

กำลังสองน้อยที่สุดสองขั้น (2SLS)

ขจัดส่วนเชิงสุ่ม (stochastic component) ที่สัมพันธ์กับค่าคลาดเคลื่อนออกจากตัวแปรภายในก่อน แล้วค่อยประมาณสมการโครงสร้าง

ข้อดี: ใช้ได้ทั้ง exactly และ over-identified ทำใน EViews ได้ด้วย LS สองรอบ

2.1 สามแบบจำลอง เทียบกันในภาพเดียว

2.2 สูตรที่ต้องจดเข้าห้องสอบ

1. Linear Probability Model

P̂ᵢ = β̂₀ + β̂₁X₁ + β̂₂X₂

แทนค่าเข้าไปในสมการ ได้ความน่าจะเป็นเลย

จุดอ่อน: ค่าอาจ < 0 หรือ > 1 และความแปรปรวนไม่คงที่ (heteroskedasticity)

2. Probit Model

Zᵢ = β̂₀ + β̂₁X₁ + β̂₂X₂

Pᵢ = F(Zᵢ) = Φ(Zᵢ)

แทนค่าหา Z ปัดทศนิยม 2 ตำแหน่ง แล้วเปิดตาราง Z (สะสมจาก −∞ ถึง Z)

Φ(−z) = 1 − Φ(z)

3. Logit Model

Zᵢ = β̂₀ + β̂₁X₁ + β̂₂X₂

Pᵢ = 1 / (1 + e−Zᵢ)

ใช้สูตรคำนวณ หา Z แล้วแทนในสูตร

odds = Pᵢ/(1−Pᵢ) = eZᵢ

ln(odds) = Lᵢ = Zᵢ

2.4 เครื่องคิดตามขั้นตอน (ลองเปลี่ยนตัวเลขได้)

ตาราง Z: Φ(z) = P(Z ≤ z) สำหรับ z ≥ 0

แถว = ทศนิยมตำแหน่งที่ 1, คอลัมน์ = ทศนิยมตำแหน่งที่ 2 ถ้า z ติดลบ ใช้ 1 − Φ(|z|)

ข้อมูลอนุกรมเวลา

บทที่ 11 · Time Series Data · บรรยาย

ประเด็นสำคัญที่จดไว้

Random Walk คือ Non-stationary จะทำให้เกิด Spurious Regression (สิ่งที่อาจารย์อยากเห็น) และ Unit Root Test

3.1 อนุกรมเวลาและความคงที่ (Stationary)

ข้อมูลอนุกรมเวลา คือข้อมูลที่เก็บรวบรวมตามลำดับเวลาที่ติดต่อกันอย่างเป็นระบบ มี 4 องค์ประกอบ: แนวโน้ม (Trend), ฤดูกาล (Season), วัฏจักร (Cycle), เหตุการณ์ผิดปกติ (Irregular)

อนุกรมเวลาที่ คงที่ (stationary) คืออยู่ในสภาวะสมดุลเชิงสถิติ คุณสมบัติทางสถิติไม่เปลี่ยนตามเวลา 3 ข้อ

E(Yt) = μ  ·  var(Yt) = E(Yt − μ)2 = σ2  ·  γk = E[(Yt − μ)(Yt+k − μ)]ค่าเฉลี่ยคงที่ · ความแปรปรวนคงที่ · ความแปรปรวนร่วมขึ้นกับระยะห่าง k เท่านั้น ไม่ขึ้นกับเวลา t

3.2 Random Walk คือ Non-stationary

Yt = Yt−1 + εt  ⇒  Yt = Y0 + Σεi  ⇒  var(Yt) = tσ2ε เป็น white noise · ความแปรปรวนโตขึ้นตามเวลา t จึงผิดเงื่อนไขข้อ 2 ⇒ ไม่คงที่ · ถ้ามีค่าคงที่ Yt = δ + Yt−1 + εt เรียก random walk with drift

เขียนรูปทั่วไป Yt = ρYt−1 + εt ถ้า ρ = 1 เรียกว่ามี unit root ซึ่งก็คือ random walk ถ้า |ρ| < 1 อนุกรมจะคงที่ ค่อยๆ ดึงกลับสู่ค่าเฉลี่ย

3.3 Spurious Regression (การถดถอยที่ไม่แท้)

สิ่งที่อาจารย์อยากเห็น

ข้อมูลที่ไม่คงที่ (เช่น random walk) ถ้านำมาถดถอยกันที่ระดับ (level) จะได้ R² สูง ค่า t มีนัยสำคัญ ทั้งที่ตัวแปรสองตัว ไม่ได้เกี่ยวข้องกันจริง เพราะทั้งคู่มีแนวโน้มเคลื่อนที่ไปตามเวลา ผลที่ได้จึงหลอกตา สัญญาณเตือนคือ Durbin-Watson ต่ำมาก (กฎของ Granger–Newbold: ถ้า R² > DW ให้สงสัย spurious)

3.4 Unit Root Test: DF และ ADF

DF: ΔYt = δYt−1 + εtH₀: δ = 0 (มี unit root, ไม่คงที่)  ·  H₁: δ < 0 (คงที่)

ถ้าค่าคลาดเคลื่อนมีสหสัมพันธ์กัน ค่าสถิติ DF จะไม่ถูกต้อง จึงเพิ่มตัวแปรล่า (lag) ของผลต่างเข้าไป เรียกว่า Augmented Dickey-Fuller (ADF)

4.2 ประโยชน์: ควบคุมตัวแปรที่วัดไม่ได้

Panel data ควบคุมปัจจัยที่ ต่างกันระหว่างหน่วย แต่ไม่เปลี่ยนตามเวลา ได้ ปัจจัยเหล่านี้ถ้าละเลยจะทำให้เกิด omitted variable bias และบ่อยครั้งวัดไม่ได้ จึงใส่ในสมการถดถอยปกติไม่ได้

แนวคิดหลัก

ถ้าตัวแปรที่ถูกละเลยไม่เปลี่ยนตามเวลา การเปลี่ยนแปลงของ Y ตามเวลาก็ไม่ได้เกิดจากตัวแปรนั้น

ตัวอย่าง: ใช้ข้อมูลปี 1982 ปีเดียวได้ FatalityRate = 2.01 + 0.15 BeerTax ภาษีเบียร์สูงขึ้นกลับมีคนตายมากขึ้น ผิดสามัญสำนึก เพราะละเลยตัวแปร เช่น ความหนาแน่นการจราจร หรือวัฒนธรรมการดื่มแล้วขับ ซึ่งสัมพันธ์กับทั้งภาษีและอัตราการตาย

  • ขจัด omitted variable bias จากตัวแปรที่คงที่ตามเวลา (Zᵢ) และตัวแปรที่เปลี่ยนตามเวลาแต่เหมือนกันทุกหน่วย (Sₜ)
  • มีจำนวนข้อมูลมากขึ้น (n × T) ความผันแปรมากขึ้น องศาอิสระมากขึ้น
  • ศึกษาการเปลี่ยนแปลงตามเวลาของแต่ละหน่วยได้

4.3 วิธีประมาณค่า เรียงจากง่ายไปดีที่สุด

ลักษณะ: Panel data (longitudinal data) คือข้อมูลที่สังเกตหน่วย n หน่วยซ้ำกันใน T ช่วงเวลา ใช้ตัวห้อยคู่ (Xᵢₜ, Yᵢₜ) i = 1…n, t = 1…T รวมข้อมูลภาคตัดขวางกับอนุกรมเวลาเข้าด้วยกัน ถ้าไม่มีข้อมูลหายเรียก balanced panel เช่น 48 รัฐ × 7 ปี = 336 ข้อมูล

ประโยชน์: ควบคุมปัจจัยที่ต่างกันระหว่างหน่วยแต่ไม่เปลี่ยนตามเวลา (Zᵢ) ซึ่งมักวัดไม่ได้ เช่น วัฒนธรรมการดื่มแล้วขับ ความหนาแน่นจราจร ทำให้ขจัด omitted variable bias ได้ เพราะถ้า Zᵢ ไม่เปลี่ยนตามเวลา การเปลี่ยนแปลงของ Y ตามเวลาก็ไม่ได้มาจาก Zᵢ อีกทั้งมีข้อมูลและความผันแปรมากขึ้น

วิธีประมาณค่า: (1) Pooled OLS ไม่ควบคุม Zᵢ (2) Changes/before–after เมื่อ T = 2 ลบสองช่วงเวลาให้ Zᵢ หายไป (3) Entity fixed effects Yᵢₜ = β₁Xᵢₜ + αᵢ + uᵢₜ ประมาณได้ด้วย n−1 binary regressors, entity-demeaned หรือ changes ให้ผลเท่ากัน (4) Time fixed effects Yᵢₜ = β₁Xᵢₜ + λₜ + uᵢₜ ควบคุมปัจจัยที่เปลี่ยนตามเวลาแต่เหมือนกันทุกหน่วย เช่น รถปลอดภัยขึ้น (5) Entity + time fixed effects Yᵢₜ = β₁Xᵢₜ + αᵢ + λₜ + uᵢₜ เหมาะสมที่สุด ควบคุมได้ทั้งสองแบบ และใช้ clustered standard errors

ตัวอย่าง: OLS ปี 1982 ได้ +0.15 เพราะละเลยตัวแปรเช่นวัฒนธรรมการดื่ม ซึ่งสัมพันธ์กับทั้งภาษีและอัตราการตาย เมื่อใช้ fixed effects ได้ −0.66 และ −0.64 คือภาษีเบียร์เพิ่ม 1 ดอลลาร์ต่อลัง อัตราการเสียชีวิตลดลงประมาณ 0.64 คนต่อประชากร 10,000 คน สอดคล้องกับทฤษฎี (time effects มีนัยสำคัญร่วมกัน F = 4.22, p = 0.0018)
